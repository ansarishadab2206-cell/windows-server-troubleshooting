# KB: User Unable to Login to Domain

## Issue
User is unable to login to the domain workstation.

## Possible Causes
- DNS misconfiguration
- Account locked or password expired
- Domain controller connectivity issue

## Troubleshooting Steps
1. Check network connectivity to domain controller
2. Verify DNS settings on client machine
3. Check user account status in Active Directory
4. Review Event Viewer logs

## Resolution
Correct DNS settings and unlock user account.

## Prevention
Ensure clients point to correct DNS server and monitor AD health.
